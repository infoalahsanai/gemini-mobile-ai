# Gemini Mobile AI Extension (Quetta / Kiwi Browser & Web) 📱✨

Google Gemini API দিয়ে চালিত লাইটওয়েট এক্সটেনশন ও মোবাইল ওয়েব অ্যাপ। এটি অ্যান্ড্রয়েডে **Quetta Browser** বা **Kiwi Browser**-এ এক্সটেনশন হিসেবে সরাসরি ইনস্টল করা যায়।

🔗 **GitHub Repo:** https://github.com/infoalahsanai/gemini-mobile-ai

---

## Quetta Browser / Kiwi Browser-এ ইনস্টল করার নিয়ম:
১. এই রিপোজিটরি থেকে কোডগুলো ডাউনলোড করুন (সবুজ **Code** বাটনে চাপ দিয়ে **Download ZIP**)।
২. আপনার ফোনের ফাইল ম্যানেজার থেকে জিপ (ZIP) ফাইলটি আনজিপ (Extract) করুন।
৩. আপনার ফোনে **Quetta Browser** বা **Kiwi Browser** খুলুন।
৪. ব্রাউজারের থ্রি-ডট মেনু থেকে **Extensions**-এ যান।
৫. উপরে ডানদিকের **Developer mode** অন করুন।
৬. **+(from .zip / .crx / userdir)** বা **Load unpacked** বাটনে চাপ দিয়ে আনজিপ করা ফোল্ডারটি সিলেক্ট করুন।
৭. এক্সটেনশনটি সফলভাবে ইনস্টল হয়ে যাবে!
৮. এবার এক্সটেনশনে ক্লিক করে ⚙️ আইকন থেকে আপনার **Google Gemini API Key** দিন এবং **"আমার API Key দিয়ে সব মডেল খুঁজুন"** বাটনে চাপলে আপনার কি-র জন্য অনুমোদিত সব নতুন মডেল চলে আসবে।
